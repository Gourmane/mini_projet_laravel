# IT Stock Manager
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
React/Vite JavaScript, plain CSS, Axios, React Router, Laravel, Sanctum sessions, SQLite.

## Users
A beginner Full Stack student learning to read, maintain and rebuild an inventory application. Demo administrator and employee roles.

## Product Purpose
Manage products and categories, record stock IN/OUT, view stock levels and immutable movement history through a real Laravel API.

## Capabilities and Constraints
French interface; preserve the original 50 seeded products and existing data. Administrator-only catalog changes. Stock changes only through movements, with transactions and reliable SQLite guards. No deployment, Docker, CI/CD or new infrastructure.

## Brand Commitments
The current brief replaces the previous SaaS design with a clean student project: light background, basic navigation, four dashboard cards, HTML tables, basic forms, standard buttons and minimal effects. Plain CSS and a system font.

## Operating Context
Local desktop and phone use. State belongs in useState within the page; simple props connect nearby components. Only authentication belongs in Context. Direct Axios calls; no Redux, generic data hooks or form frameworks.

## Product Principles
Clear beginner code, conventional Laravel, working MVP features, preserved security and stock integrity, practical Arabic learning guide, honest test results.
